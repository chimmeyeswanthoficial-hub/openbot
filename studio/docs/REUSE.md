## Adoption rule

Adopt a module only when it fits an actual need, has a verified usable license and
pin, improves the bounded implementation, and passes boundary/regression tests.
Do not import an entire bot stack just to inflate a feature count. Authentication,
budget, safety and release authority never move into donor UI defaults.
