# Work delivery, not activity theatre

Read WORKFORCE_PLATFORM.md, PROJECT_MEMORY.md and the newest feature receipt first. Keep the
independent kernel. QA/documentation is the first human-led pilot target; owned-footage editing
second. Neither is an autonomous production workforce or a specialist-parity certification.

1. Confirm a live opportunity, customer legitimacy, AI/agency eligibility, location, rights,
   budget/deadline and objective acceptance. Employment/usability studies can require a real human.
   A search hit, advertised budget or synthetic fixture is not a job won or earnings.
2. Use permitted sources/official approved APIs only. No session/cookie bots, scraping, fake
   identities/engagement, ban evasion or numeric no-ban promises. Draft social/outreach actions;
   human approval never overrides platform terms. OAuth is not blanket action consent.
3. New workbench code is OFFLINE: metadata triage/questions, bounded JUnit packets and direct
   feedback. Never add a run/send route to make the demo look autonomous. AG1/AG2 remain blockers.
4. QA packet counts actual cases, not declared totals. Bind brief/source/run/required cases;
   disclose skips/failures and host attestations. It does not run/authenticate tests or approve
   delivery. Execute customer code only after independent isolation/permission review.
5. Direct-feedback consent/source receipts, exact review, scope, expiry and revocation precede
   quoted reuse. No raw platform-data import/fine-tuning. Reviewed text remains untrusted data,
   not policy or an instruction. No model consumer is wired. Live-row redaction does not erase
   backups/exports/downstream context; expiry needs API use/explicit sweep, not imagined cron.
6. Candidate improvements need a reproducer, licensed diff, protected held-out evaluation,
   independent review and bounded human promotion/rollback. Never self-edit permissions,
   evaluator, spend ceilings, audit retention or release controls.
7. Show red→green, actual artifact/provenance and full gates. Benchmark specialist claims against
   qualified independent humans on representative held-out work; software-test count is not parity.

Run `make workforce-demo` (explicit synthetic consent/reviewer), the80 focused workbench cases,
`make lint` and `make release-check` in the locked environment. No provider, customer, social
account or background business runner is implied by a completed chat or local green check.
